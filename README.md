Exact metric dimension of bishop colour components (diamond rook reformulation, ILP computation, closed-form conjectures) — code, data, manuscript

## Overview

`bishops-graph-metric-dimension` provides algorithmic implementations and mathematical models for scientific and cryptographic applications, focusing on numerical stability, invariant verification, and performance.

## Getting Started

```bash
git clone https://github.com/rajveersinh-is-dev/bishops-graph-metric-dimension.git
cd bishops-graph-metric-dimension
pip install -r requirements.txt
```

Run the automated verification suite:

```bash
pytest tests/
```
